# 教室予約システム

Spring Boot + SQLite の教室予約アプリです。

## ロール
| ロール | できること |
|--------|-----------|
| 管理者 | 教室の追加・削除（生徒予約中は削除不可） |
| 講師   | 日付・コマ・教室を選んで授業枠を作成 |
| 生徒   | 公開された授業に予約申込み |

## 起動方法（ソースから）

```bash
mvn spring-boot:run
```

## 起動方法（JARから）

```bash
java -jar classroom-reservation-0.0.1-SNAPSHOT.jar
```

または `start.bat` をダブルクリック（Windows）

ブラウザで http://localhost:8080/login にアクセス

## 初回起動時

- 2F：201ホール(50人) 202(20人)
